Supprimer TOUTES les taxes sur les taxes : => supprimer l'impôt sur le revenu payé sur les prélèvements sociaux (CSG, CRDS) => supprimer la TVA payée sur les taxes (TVA payée sur la Taxe sur la consommation finale d'électricité, sur la Contribution au service public d'électricité, sur la Contribution tarifaire d'acheminement électricité, TVA sur la Taxe Intérieure de Consommation sur les Produits Énergétiques (TICPE), etc. etc.) : les taxes n'apportent pas de "valeur ajoutée" !
