La taxe d'habitation doit être supprimée pour les propriétaires. Une seule taxe pour les propriétaires (foncière). La taxe d'habitation pourrait être payée uniquement par les locataires.  L'impôt sur les produits de première nécessité devrait être le plus faible.  Les impôts sur les successions devraient être réduits afin de valoriser et de promouvoir l'investissement, le travail intergénérationnel.
