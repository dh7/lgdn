Augmenter, vous voulez dire ? Il faudrait augmenter les impôts sur les bénéfices des sociétés. Il faudrait augmenter les impôts sur les revenus du capital. Il faudrait augmenter les impôts sur les loyers. Il faudrait augmenter les impôts sur les hauts revenus. Il faudrait augmenter les taxes sur les produits de luxe. Il faudrait augmenter les impôts sur les transactions financières. Il faudrait augmenter les impôts sur les plus-values. Et sinon, diminuer les impôts sur les plus bas revenus.
