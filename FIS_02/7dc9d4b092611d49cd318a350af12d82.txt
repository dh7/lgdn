Ce n'est pas la bonne question (voir mes propositions). Mais, l'IR est trop élevé pour les célibataires ; l'IR n'est pas assez progressif. Les charges sociales sont beaucoup trop lourdes (ce qui explique en partie le refus de l'IR : création d'un sentiment de double peine). Si l'IR baisse pour tous, le différentiel négatif pour l'état doit être payé "à la souce" par les entreprises qui réalisent les plus gros bénéfices (= un peu moins d'argent pour les actionnaires, par exemple).
