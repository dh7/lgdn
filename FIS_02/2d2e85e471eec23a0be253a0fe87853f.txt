Supprimer la fiscalité sur les successions, il est injuste de payer pour de l’argent qui a déjà été imposé. Supprimer les impôts sur le revenu. Réduire le coût des frais de notaire lors de l’achat d’un bien. Réduire le nombre d’impôts et de taxes, les réduire à minima : taxes sur les Dépenses (ex tva), taxes sur les recettes (impôts sur le revenu) taxes sur les mauvais comportements citoyens (délits, excès de vitesse, ...), santé (alcool, cigrettes), environnementaux (gazoil, péages, déchets,), taxes solidarité (pour financer la lutte contre les sans abri, les populations en difficulté grave)
