La TVA sur les produits de base doit être baissée voire abandonnée. En revanche, la TVA sur les produits les plus polluants et les moins "nécessaires", type : haute technologie, doit être augmentée avec un taux à 50% par exemple. Pour ne pas créer un sentiment d'inégalité face à ces produits, l'Etat pourrait, comme pour le chéque énergie, mettre en place un dispositif d'aide pour l'achat d'un ordinateur ou smartphone pour les citoyens les plus pauvres. Ce dispositif serait limité dans le temps : impossibilité d'acheter un téléphone tous les ans.
