Les impôts sur le revenu pour la classe moyenne. TVA sur les produits de consommation doit être adaptée afin de changer les habitudes des consommateurs : augmenter les taxes sur les produits transformés, mauvais pour la santé, mauvais pour la planète, etc. Diminuer la TVA sur les produits respectueux de l'environnement, sains, naturels, etc. Nous aurions les moyens, par ce biais, d'avoir un réel impact sur l'environnement et la santé !
