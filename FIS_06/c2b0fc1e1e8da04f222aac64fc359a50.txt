— Aucun : en France, il faut baisser les taxes et les impôts et diminuer les dépenses publiques.  — Seule exception : augmenter les taxes sur les produits mauvais pour la santé.  Ex. : - Tabac, alcools forts (> 18°) ; - Sodas ; - Barres chocolatées ; - Confiseries, nuggets, hamburgers... ; -  D'une façon générale, toutes les préparations industrielles ultra-transformées ; - Taxer les boissons alcoolisées proportionnellement au degré d’alcool (éthanol) contenu. (Par exemple : 50° cinq fois plus taxé que 10°.)
