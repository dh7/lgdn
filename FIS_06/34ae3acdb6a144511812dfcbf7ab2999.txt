L'environnement : taxe sur tous les produits issus du pétrole, taxes sur les produits importés nocifs pour l'environnement, taxation favorisant les circuits courts, taxes sur les pesticides, taxes sur les produits polluants, etc. Je précise qu'il s'agit toujours ici de taxer les entreprises, pas les consommateurs (mais d'assumer si cela a des conséquences sur les prix que je devrai payer en tant que consommatrice) : ce n'est qu'en taxant à la source des pollutions qu'on pourra faire changer rapidement les modes de production.
