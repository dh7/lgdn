Juste = équitable. 1/ les taxes sur les produits  Les biens de bases = taxes faibles ou nulles  (ex : aliments de base, électricité, eau, gaz, les transports en communs) les autres biens = taxes + conséquente  taxes + importantes = les produits de luxe (voiture "haut gamme", produits de "marque", bijoux . . . ) 2/ Les taxes sur les revenus du travail sur tous les revenus, même les plus faibles, mais proportionnel (ex : 1 € pour les revenus les + faibles jusqu'à un plancher à définir, puis au delà progressivité) 3/ les taxes sur les produits financiers  - sur les investissements portant sur les outils productifs = taxe modérée - sur les investissements spéculatifs = taxe importante
