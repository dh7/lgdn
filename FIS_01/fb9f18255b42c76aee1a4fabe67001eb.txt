Taxer TOUTES les multinationales selon les bénéfices réalisés sur le territoire, le cas échéant sur le chiffre d'affaires De nombreuses niches fiscales existent : 1- supprimer celles ayant pour objectif les placements financiers. 2- Affecter celles qui ont un objet social de plafonds de ressources, le cas échéant progressifs. 3- soumettre TOUS les ménages à l'IRPP, fut-ce d'un seul €  pour les plus démunis, même si cela coûte un peu aux services fiscaux. Cela rétablirait la valeur symbolique de l'impôt, laquelle est essentielle pour son acceptation. 4- revoir les échelles d'imposition, avec plusieurs échelons supplémentaires pour les revenus très élevés. Eviter que l'IRPP soit concentré sur les classes moyennes. 5- Taxer très lourdement le transport poids lourds de transit et favoriser le ferroutage. 6- Au lieu de diminuer le nombre de fonctionnaires, renforcer le contrôle fiscal et douanier. Instituer des "taxes sociales" conséquentes sur les produits importés de pays à très bas coût de main d'oeuvre
