Deux constats sur les baisses de charges sur les salaires : 1) Les baisses sur les très bas salaires tirent les salaires vers le bas les employeurs y ayant tout intérêt . 2) Aucun effet sur l'emploi pour les salaires  au delà de 3 fois le smic Je propose donc deux aménagements: 1) Baisse des charges à partir de 1,25 fois le smic (ceci pourrait avoir pour effet de faire remonter les très bas salaires)  2) Supprimer les baisses de charges à partir de 3 fois le smic.
