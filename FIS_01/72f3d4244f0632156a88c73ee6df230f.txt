Application systématique d’un taux d’imposition identique à tous les itoyens ( 10% ) sur chaque transaction financière : les salaires, les dividendes, les facturations... Avec objectif que tous les individus paient sur un territoire.  Simplifier les impôts par l’arrêt des niches et des particularités.  Faire voter les citoyens sur les types de frais publics qu’ils veulent financer par l’impôt ; donner auparavant les indications des besoins chiffrés. Ce vote peut être annuel ou pluri annuel ( à 3 ans maxi ).
