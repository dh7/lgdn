Créer trois types de TVA :   -TVA de "première nécessité" pour les produits dont on ne peut pas se passer (TVA symbolique à 1% pour l'eau, l'électricité, le gaz les denrées alimentaires de première nécessité, les produits d'hygiène de base, une voiture basique, un téléphone basique, un ordinateur basique,...),  -TVA de "confort" concernant les produits pour les loisirs mais qui peuvent être également essentiels au quotidien (TVA à 25% pour l'essence, les livres, le cinéma, les vêtements, les voyages en France, les transports, les loisirs, la culture,...) -TVA de "luxe" pour les produits dont on peut se passer (TVA à 50% pour les iphones, les bijoux, l'alcool, le tabac, les voitures non-basiques, les voyages à l'étranger, les home-cinémas, les bateaux, les avions, tous les produits de luxe...)
