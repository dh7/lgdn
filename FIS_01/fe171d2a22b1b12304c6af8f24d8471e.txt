Impôts sur le revenu : tout le monde devrait contribuer, même symboliquement pour les plus faibles revenus ; augmenter le nombre de tranches et le taux pour les très hauts revenus (les 1% les plus hauts). Fiscalité locale : supprimer  les disparités entre les taux d'impositions (communes, intercommunalité, départements). Supprimer les taxes sur les taxes (exemples : carburants, électricité...).
