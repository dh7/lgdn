REFORMER LA TVA = taux zero pour les produits de première nécessité comme le pain, le lait....ect....; taux reduit (5.5) pour les produits de consommation courante non de 1ere nécessité mais devenu indispensable pour vivre décemment (alimentation, vêtements,automobile, électroménager...ect de premier prix) ; taux intermédiaire (environ 15%) pour les produits de confort dans les gammes intermédaires ; taux plein (environ 20%) pour les produits de confort haut de gamme ; taxe renforcée (25 à 30%)pour les produits de  luxe .  MODIFIER LES TRANCHES d'IMPOTS SUR LE REVENU / moins taxer les revenus moyens et augmenter les tranches pour les revenus élevés.
