En matière d'institutions, je trouve que l'organisation de notre parlement est totalement inefficace. l'existence de deux chambres qui statuent sur la même chose est une source de perte d'énergie et d'irresponsabilité : les sénateurs ou les députés relèvent le menton pour satisfaire leurs électeurs tout en sachant que l'autre chambre ou la commission mixte paritaire édulcorera leur texte et ramènera leurs décisions à de justes proportions. Je propose que chaque chambre ait ses propres compétences : Pour l'assemblée, toutes les lois répressives et les grandes décisions sociétales (= code pénal, code civil, code de procédures, tout ce qui concerne les libertés ... etc) Pour le sénat, tout ce qui concerne l'aménagement et l'égalité des territoires : les transports, la formation, la sécurité sociale ( = grosso modo : code de l'urbanisme, code du travail, code rural, code de la sécu) On pourrait garder un parlement réuni en congrès avec les mêmes compétences que le référendum = adoption des traités internationaux, lois organiques, modifications constitutionnelles, engagement de la France dans des opérations extérieures  belliqueuses.
