Reprenons :   1/ Il faut rendre la fiscalité plus redistributive : Si on se base sur la notion de revenu disponible, on peut créer une sécurité sociale unifiée garantissant à chacun des moyens d'existence dignes : logement, nourriture, éducation, santé, accès aux services publics et aux services qui devraient l'être (électricité, internet, etc), ainsi qu'à un minimum de loisirs. Tout ceci, bien évidemment, sans contrepartie : Parler de «valeur travail» n'est qu'une imposture et une contradiction : le travail est une activité et un moyen, pas une fin, surtout pour le travail salarié (au seul bénéfice d'autres) ou même précaire/ubérisé.   2/ Cette redistribution doit être financée par les grands gagnants du système, et notamment :  Il faudrait augmenter les impôts sur les bénéfices des sociétés. Il faudrait augmenter les impôts sur les revenus du capital. Il faudrait augmenter les impôts sur les loyers. Il faudrait augmenter les impôts sur les hauts revenus. Il faudrait augmenter les taxes sur les produits de luxe. Il faudrait augmenter les impôts sur les transactions financières. Il faudrait augmenter les impôts sur les plus-values. Il faut taxer les rentes de manière général. Il faut augmenter les charges patronales. Et sinon, diminuer les impôts sur les plus bas revenus.  3/ Une fois la redistribution effectuée, il est urgent de réinvestir cet argent dans les domaines de l'action publique utiles aux citoyens : Éducation, Recherche, Justice, et Culture en priorité. Désarmer la police.   4/ Enfin, pour assurer le consentement à l'impôt, publier en open data tous les salaires de tous les agents publics, toutes les dépenses publiques, toutes les recettes publiques, tous les contrats publics, toutes les indemnités, etc. Le budget de l'état doit être public, de l'achat d'un stylo bic à la vente de parts dans un aéroport, et les différences avec le budget prévisionnel doivent être justifiables par le gouvernement.
