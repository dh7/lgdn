Fisc / Impôt juste : Chacun donne selon ses moyens ; chacun reçoit selon ses besoins = §§ - Rétablir ISF // - Lutte effective contre l'évasion fiscale // - Impôts sur tous revenus particuliers et d'entreprise, au même taux, en 16 tranches, de 5 à 80 % (dans système où chacun reçoit le Revenu Universel de 1.300) // - Fin dérogations et niches fiscales (sauf écologiques) // - Baisse TVA sur produits de 1ère nécessité, notamment alimentaires // - Taxe sur CA, à augmenter // - Taxe sur activités financières // - Taxe sur spéculations autorisées // - Taxe sur GAFA // - Successions : exonération jusqu'à 400.000 euros, par héritier (prix d'un Logement pour une famille). Ensuite, totalité à l'Etat.
