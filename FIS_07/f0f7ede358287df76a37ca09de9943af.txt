Évasion fiscale doit être condamnée. Rétablir l'ISF et maintenir l'IFI. Augmenter la TVA sur les produits de luxe. Augmenter le droit de douane sur les produits de luxe, nocifs... Augmenter la CSG sur les salaires plus importants. Revoir les exonérations sur les impôts sur le revenu. Ajouter des paliers sur les taux de l'impôt sur les sociétés : 15% sur les bénéfices inférieurs à 35k€ - 20% sur les bénéfices entre 35 et 70k€ - 25% sur les bénéfices entre de 70k€ et 100k€ - 30% sur les bénéfices au-delà de 100k€. Taxer les marges importantes fixées par les sociétés (ou plafond sur les produits de 1ere nécessité). Maintenir la taxe d'habitation à ajuster selon le restant à vivre des foyers. Augmenter la taxe foncière sur les résidences secondaires. Passer le calcul de la taxe sur le chiffre d'affaires des exploitants agricoles au bénéfice net. Augmenter les taxes sur les publicités diffusées sur les chaînes de télévision. Rétablir l'impôt sur les opérations de bourse. Faire payer les consultations dans les service d'Urgence en fonction du diagnostic avéré.
