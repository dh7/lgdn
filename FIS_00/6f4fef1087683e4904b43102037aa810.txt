Ne pas faire de campagne de pub très onéreuse en plus. Utiliser les supports existants (formulaires cerfa ou autres) pour préciser comment l'aide ou le dispositif sollicité est financé.  Prévoir une autonomie du financement pour les différentes instances publique avec des impôts fléchés : les impôts sur le revenu pour les services régaliens, la TVA pour l'économie, l'agriculture…  les impôts sur les entreprises pour les régions, les impôts sur l'habitat pour les communes par exemple.
